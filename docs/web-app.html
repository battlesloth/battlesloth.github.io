Setup Guide/The Web App
Chapter 05 · Using AstrOs

Use the AstrOs web app.

With your nodes flashed and paired, everything else happens in AstrOs.Server — the web app where you configure hardware, script animations, build playlists and drive your droid.

i
These screens are pre-1.0

AstrOs is under active development, so the web app may look slightly different from the screenshots here. The flow stays the same.

§Log in

Browse to your server's address (from Server Setup). The app opens to a single password prompt — enter your server password and select Login.

§Find your way around

The menu (top-left) opens the screens you'll use. For setup you'll work through them roughly in this order:

  • Modules — tell each node what hardware it controls. Start here →
  • Scripts & Playlists — author animations and sequence them. (Coming soon.)
  • Remote — configure the touchscreen / mobile remote. (Coming soon.)
  • Firmware — push OTA updates to your nodes. (Coming soon.)

§Your home base: Status

The app opens on the Status dashboard — a live view of every node and the health of its link to the server. Check back here whenever you change configuration to confirm each node is online and in sync.
