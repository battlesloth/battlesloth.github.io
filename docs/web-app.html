Setup Guide/The Web App
Chapter 05 · Using AstrOs

Use the AstrOs web app.

With your nodes flashed and paired, everything else happens in AstrOs.Server — the web app where you configure hardware, script animations, build playlists and bring your droid to life.

i
Active Development

AstrOs is under active development, so the web app may look slightly different from the screenshots here. The flow stays the same.

§Log in

Browse to your server's address (from Server Setup). The app opens to a single password prompt — enter your server password and select Login. The default password is password. Make sure to change it after your first login on the Utility page.

§Find your way around

The menu (top-left) opens the screens you'll use. For setup you'll work through them roughly in this order:

  • Modules — tell each node what hardware it controls. Start here →
  • Scripts & Playlists — author animations and sequence them.
  • Remote — configure the touchscreen / mobile remote.
  • Firmware — push OTA updates to your nodes.
  • Utility — housekeeping: the remote's API key, SD-card formatting, logs and your password.

§Your home base: Status

The app opens on the Status dashboard — a live view of every node and the health of its link to the server. Grey indicates a node is offline, red indicates a node's firmware is not compatible with the server and needs updating, and yellow indicates a node's configuration is out of sync.

First stop: tell each node what it controls.
