Setup Guide/Pairing Nodes
Chapter 04 · Pairing

Link your master & padawans.

A droid can have several nodes. One is the master — wired to the server. The rest are padawans, linked to the master wirelessly over ESP-NOW. Here's how to assign those roles and get them talking.

The server only ever talks to the master. The master fans commands out to the padawans over ESP-NOW and polls each one every 2 seconds to keep tabs on them — so you can scatter nodes around the droid with no wires running between them.

§Pair them up

  1. 1
    Power on every node

    Make sure all your flashed nodes are powered and physically near each other for the first pairing. ESP-NOW is good over distance, but a clear first handshake never hurts.

  2. 2
    Turn on Discovery Mode on the Master

    On the Master, hold down the ESP32 Mode button for 5 seconds to enter Discovery Mode — the master's pairing mode. The Mode button is the button you connected to the ESP32, not any of the built in buttons. On release, the OLED should display "Discovery Mode On". It listens for ESP-NOW registration messages from the padawans and records each one's MAC address as a known peer. Roles and peers are saved to each board's storage, so they're remembered across reboots.

  3. 3
    Register each Padawan

    On each padawan, hold the ESP32 Mode button for 5 seconds. The padawan will send a registration message to the master. The master responds with the Padawan's assigned name. Once registered, the padawan will display its assigned name on the OLED and automatically exit discovery mode.

  4. 4
    Turn off Discovery Mode on the Master

    Once you have registered all padawans, turn off Discovery Mode on the Master by holding the ESP32 Mode button for 5 seconds. On release, the OLED should display "Discovery Mode Off" and change to "Master Node" after a few seconds.

  5. 5
    Register your controllers in the web app

    Ensure your Master is connected to your server via serial and all the nodes are powered on. In AstrOs.Server, open the Modules page and assign a padawan to the Dome and Core. The Master is always assigned to the Body by default. Once assigned, click the Save button.

  6. 6
    Push your configuration

    Send the configuration from the server by clicking the "Sync" button in the Modules page. Your servo, serial, I²C, and GPIO module assignments flow out to the master and on to each padawan, so every node knows which hardware it owns.

  7. 7
    Confirm the link is healthy

    The Status page in AstrOs.Server shows the health of the link between the master and each padawan. Ensure all nodes are communicating correctly. A greyed out section indicates a node is not responding. Blinking red indicates a node's firmware is not compatible with the server and needs updating. Blinking yellow indicates a node's configuration is out of sync and you need to sync the configuration from the modules page.

i
Roles live on the board

A node's role and its peer list are stored in non-volatile memory and applied at boot — you never reflash to change master vs padawan. Reassign locations any time from the server.

!
Exactly one master

Only one node per droid may be the master — it's the single owner of the server link and the poll cycle. Two masters will fight over the network. If you're moving the master role, demote the old one first.

That's a working droid brain.
