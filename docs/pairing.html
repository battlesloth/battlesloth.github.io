Chapter 04 · Pairing

Link your master & padawans.

A droid can have several nodes. One is the master — wired to the server. The rest are padawans, linked to the master wirelessly over ESP-NOW. Here's how to assign those roles and get them talking.

The server only ever talks to the master. The master fans commands out to the padawans over ESP-NOW and polls each one every 2 seconds to keep tabs on them — so you can scatter nodes around the droid with no wires running between them.

§Pair them up

  1. 1
    Power on every node

    Make sure all your flashed nodes are powered and physically near each other for the first pairing. ESP-NOW is good over distance, but a clear first handshake never hurts.

  2. 2
    Register your controllers in the web app

    In AstrOs.Server, open the controller configuration and add an entry for each node. Your master is the node you flagged with config.txt and wired to the Pi (see Flashing Firmware); the rest are padawans.

  3. 3
    Run discovery on the master

    Kick off the master's discovery/registration. It broadcasts over ESP-NOW, finds the padawans, and records each one's MAC address as a known peer. Roles and peers are saved to each board's storage, so they're remembered across reboots.

  4. 4
    Push your configuration

    Send the configuration from the server. Your servo, serial and GPIO module assignments flow out to the master and on to each padawan, so every node knows which hardware it owns.

  5. 5
    Confirm the link is healthy

    The master now polls each padawan every 2 seconds. If you fitted OLED displays, each shows its role and link status; otherwise watch the master's serial log for poll acknowledgements from every node.

i
Roles live on the board

A node's role and its peer list are stored in non-volatile memory and applied at boot — you never reflash to change master vs padawan. Reassign roles any time from the server and re-run discovery.

!
Exactly one master

Only one node per droid may be the master — it's the single owner of the server link and the poll cycle. Two masters will fight over the network. If you're moving the master role, demote the old one first.

✦
Exact buttons may shift

AstrOs is pre-1.0 and the configuration UI is still evolving, so the precise menu names in the web app may differ from the flow above. The concepts — register nodes, pick a master, discover peers, push config — stay the same. The AstrOs.Server repo has the latest.
