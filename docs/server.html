Chapter 03 · Server

Run the AstrOs server.

AstrOs.Server is the web app where you design animations and manage your nodes. It runs as a Docker container on a single-board computer — a Raspberry Pi or Orange Pi — wired to your master node over serial.

Use a 64-bit OS

The server image is built for linux/arm64/v8, so flash your Pi with a 64-bit Raspberry Pi OS (or equivalent). A Pi 4 / Pi 5 or a comparable Orange Pi works well.

§Free up the serial port

The container talks to your master node through the Pi's hardware UART. By default the Pi uses that port for a login console — you need to turn the console off and the serial hardware on. NOTE: Orange Pi requires significantly different steps - consult your board's documentation.

raspberry pi
sudo raspi-config
#  → Interface Options → Serial Port
#      Login shell over serial?   No
#      Serial port hardware?      Yes

sudo reboot

After the reboot the UART is available at /dev/ttyAMA0 (mapped into the container as /dev/ttyS0 by the compose file below).

§Install Docker

  1. 1
    Install the Docker engine
    raspberry pi
    sudo apt update && sudo apt install -y docker.io
  2. 2
    Create the server's data folder

    This is where AstrOs keeps its database and logs — the compose file mounts it into the container, so your animations survive restarts and updates.

    raspberry pi
    mkdir -p ~/.config/astrosserver
  3. 3
    Create the Docker network

    AstrOs runs on an external bridge network named astronet:

    raspberry pi
    docker network create astronet

§Deploy the stack

Save the compose file below as docker-compose.yml. Edit two things first: set CORS_ORIGIN to your Pi's IP address, and make sure the volume path matches the folder you created (the example uses the astros user's home).

docker-compose.yml
services:
  astros:
    image: 'ghcr.io/battlesloth/astros-server:latest'
    restart: unless-stopped
    ports:
      - 80:80      # web UI
      - 5000:5000  # realtime / WebSocket
      - 3000:3000  # API
    volumes:
      - /home/astros/.config/astrosserver:/root/.config/astrosserver
    environment:
      - CORS_ORIGIN=http://<your-pi-ip>
    networks:
      - astronet
    devices:
      - '/dev/ttyAMA0:/dev/ttyS0'   # Pi UART → container

networks:
  astronet:
    external: true

Then bring it up from the same folder:

raspberry pi
docker compose up -d
✦
Prefer a UI? Use Portainer

Many builders manage the stack with Portainer instead of the CLI. Install it, create the astronet network under Networks, then add a Stack named astros and paste the compose file above. Same result, friendlier buttons.

§Open the web app

Point a browser on the same network at your Pi's address:

browser
http://<your-pi-ip>/

You should land on the AstrOs animation studio. The last wiring detail: connect the Pi's UART to your master node.

!
Cross your TX and RX

Wire the Pi's serial TX → master node RX and Pi RX → master node TX, and join their grounds. Transmit always goes to the other side's receive — straight-through wiring is the classic "why won't it talk" gotcha.
