New to AstrOs?

AstrOs is an animation scripting and control system for R2 builders. You design animations in a web app, and one or more ESP32 nodes inside your droid play them back by driving servos, sound, lights and more. It doesn't handle drive/motion, but plays nicely alongside existing drive systems.

§How the pieces fit together

AstrOs is made of a few interconnected projects. For setup you only need the first two — the touchscreen remote is optional and used mainly at events.

🖥

AstrOs.Server runs on a Pi

A Node.js + Vue web app in a Docker container. You design animations and manage node configuration here. Talks to the ESP32 nodes over a serial connection.

⌁

AstrOs.ESP ESP32 firmware

The firmware on each ESP32 node in your droid. One node is the master (wired to the server); the rest are padawans linked wirelessly over ESP-NOW. Drives your servos, sound and GPIO.

§What you'll need

A rough shopping list for your build. Some assembly required.

Adafruit Metro ESP32-S3

One per node, typically three nodes in an R2. 16 MB flash, native USB-C, STEMMA QT. (Product #5500)

SSD1306 OLED (128 x 32 pixels)

Small I²C status display — shows node role & health.

Single-board computer

Raspberry Pi or Orange Pi with a free serial port — runs the server.

Micro SD Card

One SD Card for each ESP32 node and one for the single-board computer (SBC). Some SBCs support NVMe hard drives and can be used for the SBC instead.

Power for ESP32 nodes

5V USB, 4.2/3.7V LiPo, or 6-12V DC through the barrel connector.

Button, cables & misc

A momentary Mode button for each node, USB-C cable for flashing, STEMMA QT / jumper wires, plus your servos, sound board, etc.
